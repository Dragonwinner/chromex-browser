# 🔒 Security Policy

## Supported Versions

We actively provide security updates for the latest released version of **ChromeX Browser**.

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0.0 | :x:                |

---

## Reporting a Vulnerability

The security of ChromeX Browser and its users is a top priority.

If you discover a security vulnerability:

1. **Do NOT open a public GitHub issue.**
2. Please report the issue privately using [GitHub Security Advisories](https://github.com/Dragonwinner/chromex-browser/security/advisories/new) or by reaching out to the maintainer.
3. Include:
   - Detailed description of the vulnerability.
   - Steps to reproduce or proof-of-concept.
   - Potential impact and affected versions.

We will acknowledge receipt within 48 hours and work with you to test and release a security patch as quickly as possible.
